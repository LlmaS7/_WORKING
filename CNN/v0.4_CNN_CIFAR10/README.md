# CNN v0.4：CIFAR-10 图像分类

本项目使用 PyTorch 构建卷积神经网络，完成 CIFAR-10 十分类任务。代码由原单文件 `CNN_v0.4_PyTorch_CIFAR10.py` 拆分为数据处理、模型、训练和可视化等模块，便于阅读和调整实验。

项目包含训练集与验证集划分、训练数据增强、学习率调度、早停、测试集评估，以及训练曲线和样本预测展示。

## 目录结构

```text
v0.4_CNN_CIFAR10/
├── main.py           # 程序入口，组织训练、验证、测试和绘图
├── config.py         # 超参数、数据路径、归一化参数和类别名称
├── data.py           # 数据预处理、数据集划分和数据加载器
├── model.py          # 卷积神经网络 Net
├── training.py       # 单轮训练、评估和早停逻辑
├── visualize.py      # 训练曲线和样本预测展示
├── requirements.txt  # Python 依赖
└── README.md         # 项目说明
```

## 安装与运行

需要 Python 环境，依赖为 `torch`、`torchvision` 和 `matplotlib`。在 PowerShell 中进入项目目录，安装依赖并运行：

```powershell
cd E:\_WORKING\CNN\v0.4_CNN_CIFAR10
python -m pip install -r requirements.txt
python main.py
```

程序在 CUDA 可用时自动使用 GPU，否则使用 CPU。首次运行会自动下载 CIFAR-10，因此需要联网。

数据根目录由 `config.py` 中的 `DATA_ROOT` 控制，默认值为 `""`，数据会放在当前工作目录下。若需要指定位置，可改为：

```python
DATA_ROOT = r"E:\_WORKING\datasets"
```

当前依赖文件未固定版本；项目也未提供命令行参数，运行前请直接在 `config.py` 中修改配置。

## 数据与预处理

CIFAR-10 图像大小为 `32 × 32`，包含 3 个颜色通道。十个类别依次为：飞机、汽车、鸟、猫、鹿、狗、青蛙、马、船和卡车。代码与预测图使用对应的英文类别名称。

默认划分如下：

| 数据集 | 样本数 | 用途 |
| --- | ---: | --- |
| 训练集 | 45,000 | 更新模型参数 |
| 验证集 | 5,000 | 调整学习率、监测早停和选择模型 |
| 测试集 | 10,000 | 训练结束后的最终评估 |

训练集和验证集从官方的 50,000 张训练图像中划分，使用随机种子 `42` 固定划分结果。训练样本使用随机裁剪（边缘填充 4 像素）和随机水平翻转；验证与测试样本不使用随机增强。

所有样本都会转换为张量并按通道归一化：

- 均值：`(0.4914, 0.4822, 0.4465)`。
- 标准差：`(0.2470, 0.2435, 0.2616)`。

## 网络结构

模型包含三个卷积块，每个块依次执行两组「卷积 → 批归一化 → ReLU」，再通过最大池化缩小空间尺寸。所有卷积均使用 `3 × 3` 卷积核、填充 `1`，并关闭卷积偏置。

| 阶段 | 输出形状（不含批次维度） |
| --- | --- |
| 输入图像 | `3 × 32 × 32` |
| 卷积块 1 + 最大池化 | `64 × 16 × 16` |
| 卷积块 2 + 最大池化 | `128 × 8 × 8` |
| 卷积块 3 + 最大池化 | `256 × 4 × 4` |
| 全局平均池化 + 展平 | `256` |
| Dropout + 全连接层 | `10` |

最后输出十个类别的原始分数（logits），训练时直接传入交叉熵损失，预测时取分数最大的类别。

## 默认训练配置

主要参数集中在 `config.py`：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `SEED` | `42` | 数据划分与 PyTorch 随机种子 |
| `TRAIN_BATCH_SIZE` | `128` | 训练批次大小 |
| `EVALUATION_BATCH_SIZE` | `1000` | 验证和测试批次大小 |
| `VALIDATION_SIZE` | `5000` | 验证集样本数 |
| `LEARNING_RATE` | `1e-3` | AdamW 初始学习率 |
| `WEIGHT_DECAY` | `5e-4` | AdamW 权重衰减 |
| `LABEL_SMOOTHING` | `0.05` | 训练交叉熵的标签平滑系数 |
| `MAX_EPOCHS` | `100` | 最大训练轮数 |
| `DROPOUT` | `0.2` | 全连接层前的丢弃概率 |
| `SCHEDULER_FACTOR` | `0.5` | 学习率下降时的乘数 |
| `SCHEDULER_PATIENCE` | `3` | 学习率调度器的耐心参数 |
| `USE_EARLY_STOPPING` | `True` | 是否启用早停 |
| `EARLY_STOPPING_PATIENCE` | `12` | 允许连续未改善的轮数 |
| `EARLY_STOPPING_MIN_DELTA` | `1e-4` | 早停判定的最小改善阈值 |

学习率调度器使用 `ReduceLROnPlateau`，监测验证损失。早停同样监测验证损失：当损失较已记录的最佳值下降超过 `1e-4` 时，更新最佳模型；连续 12 轮未达到该条件则停止训练。

训练损失使用标签平滑，验证与测试损失使用普通交叉熵，因此两者的计算方式有所不同。固定随机种子不代表不同设备或环境下的训练结果完全一致。

## 运行流程与输出

1. 设置随机种子，选择运行设备并加载数据。
2. 构建模型，输出训练前的验证损失和准确率。
3. 每轮训练后进行验证，更新学习率并检查早停条件。
4. 启用早停时，训练结束后恢复早停逻辑记录的最佳模型，再评估测试集；关闭早停时使用最后一轮模型。
5. 展示训练损失、验证损失、验证准确率曲线，以及默认 4 张测试样本的预测结果与真实标签。

控制台会打印设备、每轮损失、验证准确率、学习率、早停计数，以及最终测试结果。准确率以 `0～1` 的小数表示，例如 `0.85` 表示 `85%`。

图像通过 Matplotlib 窗口展示，需要支持图形显示的运行环境。当前代码不会自动将图像、训练日志或模型权重保存为文件；早停的最佳模型状态仅保存在内存中。实际准确率需以运行结果为准，项目未附带训练成绩记录。
