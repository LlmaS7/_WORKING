# CNN v0.5：CIFAR-10 残差网络

本版本与 `../v0.4_CNN_CIFAR10/` 并行，使用适合 `32 × 32` 图像的残差网络。
整体采用 ResNet-20 风格的三阶段结构，将基础通道数从经典 CIFAR ResNet 的 16
调整为 32；不是 ImageNet 版 ResNet-18，也不是在 v0.4 的池化块外简单加一条连接。

## 运行

在工作区现有虚拟环境中运行：

```powershell
cd E:\_WORKING\CNN\v0.5_CNN_CIFAR10
& E:\_WORKING\.venv\Scripts\python.exe main.py
```

其他环境需要先安装 `requirements.txt` 中的依赖，再执行 `python main.py`。
数据路径指向父目录 `CNN/`，与 v0.4 共用已有 CIFAR-10 数据。
数据不存在时会自动下载。配置均在 `config.py` 中修改。

## 网络结构与调整原因

| 阶段 | 结构 | 输出形状（不含批次维度） |
| --- | --- | --- |
| 输入 | CIFAR-10 彩色图像 | `3 × 32 × 32` |
| Stem | `3×3 Conv → BN → ReLU`，步长 1 | `32 × 32 × 32` |
| Stage 1 | 3 个残差块，步长均为 1 | `32 × 32 × 32` |
| Stage 2 | 3 个残差块，第一个块步长为 2 | `64 × 16 × 16` |
| Stage 3 | 3 个残差块，第一个块步长为 2 | `128 × 8 × 8` |
| 分类头 | 全局平均池化 → 展平 → Dropout → Linear | `10` |

每个残差块的主分支：

```text
x → 3×3 Conv → BN → ReLU → 3×3 Conv → BN ─┐
│                                        + → ReLU
└→ shortcut ─────────────────────────────┘
```

- 同一阶段内的 shortcut 为恒等映射；跨阶段使用 `1×1 Conv → BN`，
  与主分支同时缩小空间尺寸、增加通道数，确保相加时形状匹配。
- 第二个卷积后先做 BN，再与 shortcut 相加，最后做 ReLU。
  不在相加前截断主分支的负值，使它可以学习正、负修正。
- 删除 v0.4 的三次最大池化；只在后两个阶段入口下采样，
  保留小图像的空间细节，并让下采样成为可学习操作。
- 增加深度的同时减小通道宽度：默认有 9 个残差块、19 个主干卷积层和
  1 个全连接层（20 层的计数不包含 shortcut 投影卷积）。
- 卷积使用 Kaiming 初始化；各残差分支最后一个 BN 的缩放系数初始为 0，
  让网络从 shortcut 路径附近开始学习。跨阶段仍由投影 shortcut 完成变换。
- 保留全局平均池化与单层分类头，将分类头 Dropout 从 `0.2` 调整为 `0.1`。
  这是较轻正则化的实验起点，并不代表已经验证优于 `0.2`。

`BASE_CHANNELS = 32` 控制宽度，`BLOCKS_PER_STAGE = (3, 3, 3)` 控制深度。
最终输出是 logits，直接用于交叉熵，模型内部不添加 Softmax。

### 残差连接开关

在 `config.py` 中修改 `USE_RESIDUAL`，然后重新运行 `main.py`：

```python
USE_RESIDUAL = True   # 开启：ReLU(F(x) + shortcut(x))，保持原有默认行为
# USE_RESIDUAL = False  # 关闭：ReLU(F(x))，使用同深度的普通卷积网络
```

关闭后保留主分支的层数、通道数、步长、分类头及训练设置，不会变回 v0.4。
不再创建跨阶段的 shortcut 投影，因此参数量会略少。
关闭模式下每个块最后一个 BN 的缩放系数初始化为 1；开启时仍为 0。
这是为了避免没有 shortcut 时零初始化截断信号及梯度，导致网络无法正常训练。
控制台会显示当前开关值与实际参数量。切换后应从头训练；实验对比时记录开关值，
保持其他配置一致，并用多个随机种子重复比较。

| 对比项 | v0.4 | v0.5 |
| --- | --- | --- |
| 可训练参数量 | 1,148,874 | 1,084,586 |
| 主干卷积层数 | 6 | 19 |
| 特征阶段通道 | `64 → 128 → 256` | `32 → 64 → 128` |
| 各阶段结束时的空间尺寸 | `16 → 8 → 4` | `32 → 16 → 8` |
| 下采样 | 三次最大池化 | 两次步长卷积与对应 shortcut 投影 |
| 分类头 Dropout | `0.2` | `0.1` |

## 训练与评估

保留 v0.4 的固定数据划分：45,000 训练样本、5,000 验证样本、10,000 测试样本。
随机种子为 42，训练数据使用随机裁剪与水平翻转，验证和测试使用确定性预处理。

| 配置 | 默认值 |
| --- | --- |
| 优化器 | AdamW |
| 初始学习率 | `1e-3` |
| Weight decay | `5e-4` |
| 训练 Label smoothing | `0.05` |
| 训练 / 评估 Batch size | `128 / 1000` |
| 最大训练轮数 | `100` |
| 调度器 | ReduceLROnPlateau，factor `0.5`，patience `3` |
| 早停 | 验证损失，patience `12`，min_delta `1e-4` |

先沿用现有优化器、学习率调度和数据增强，以便观察结构变化。
训练结束后恢复早停逻辑在内存中保留的最佳权重，再评估测试集；
关闭早停时沿用最后一轮权重。程序显示训练曲线和样本预测，不生成实验存档。
训练损失包含标签平滑，验证与测试损失不包含，因此不能只比较两者数值判断过拟合。

本版本尚未完成完整训练，准确率提升需要实测。它与 v0.4 的网络结构不同，
不能直接加载 v0.4 的模型权重；应从头训练。更深的网络可能增加实际运行时间，
参数量接近不代表延迟或显存占用相同。

运行检查（使用现有虚拟环境）：

```powershell
& E:\_WORKING\.venv\Scripts\python.exe -m unittest -v test_model
```

CPU 检查包含六项，覆盖恒等/投影 shortcut、相加前的负残差、两种开关模式的推理、
关闭残差后的信号与首步梯度、参数更新和最佳状态恢复。此前另使用本地 CIFAR-10 的 128 个训练样本、64 个验证样本、
64 个测试样本完成两轮默认网络的 GPU 短跑，确认 `main.py` 的训练、验证、
测试和绘图流程可运行。这些检查不代表完整训练后的分类成绩。

结构参考：[Deep Residual Learning for Image Recognition](https://arxiv.org/abs/1512.03385)。
